# 할 일 카드 웹앱

할 일을 카드로 만들고, 카드의 상태를 "할 일", "진행 중", "완료" 중 하나로 직접 바꾸는 웹앱입니다.

## 현재 상태

- 요구사항과 설계 문서를 확정했고, 구현 중입니다 (PLAN.md P-10~P-20). 정하지 않은 것은 각 문서의 "열린 질문"에 남아 있습니다.
- 코드는 `frontend/`의 화면 틀(P-11)과 `backend/`의 서버 틀(P-12)이 있습니다. 화면은 Vite 프록시로 서버에 연결되어(P-13) 카드 목록을 받아 세 칸에 보여 줍니다. 카드 만들기·고치기·지우기·상태 바꾸기는 아직 없습니다.
- 이 폴더는 Git 저장소로 기록합니다 (D-005). 원격 저장소는 정하지 않았습니다.
- 앱 안에는 AI 기능을 넣지 않습니다.

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들어졌는지 확인합니다.

## 실행 방법

아직 정하지 않았습니다. 앱을 만든 뒤 이곳에 적습니다.

## 확인과 기록

- 무언가를 만들거나 바꾸면 "현재 상태"를 그에 맞게 고칩니다.
- 새 문서를 만들면 "프로젝트 문서" 표에 추가합니다.
