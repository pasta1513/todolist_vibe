# 할 일 카드 웹앱

할 일을 카드로 만들고, 카드의 상태를 "할 일", "진행 중", "완료" 중 하나로 직접 바꾸는 웹앱입니다.

## 현재 상태

- 요구사항과 설계 문서를 확정했고, 구현 중입니다 (PLAN.md P-10~P-21). 정하지 않은 것은 각 문서의 "열린 질문"에 남아 있습니다.
- 코드는 `frontend/`의 화면 틀(P-11)과 `backend/`의 서버 틀(P-12)이 있습니다. 화면은 Vite 프록시로 서버에 연결되어(P-13) 카드 목록을 받아 세 칸에 보여 줍니다. 카드 만들기(P-14), 상태 바꾸기(P-16), 고치기·지우기(P-17)가 됩니다. 칸에 방금 들어온 카드는 맨 아래에 놓입니다(P-21). 화면 폭이 768px보다 좁으면 세 칸이 세로로 쌓입니다(P-15). 저장·연결에 실패하면 화면 위쪽에 안내가 보입니다(P-18). 다 만든 뒤에는 서버 하나만 켜서 쓸 수 있습니다(P-19, D-013). 실행 방법은 아래 "실행 방법"을 봅니다.
- 이 폴더는 Git 저장소로 기록합니다 (D-005). 원격 저장소는 정하지 않았습니다.
- 앱 안에는 AI 기능을 넣지 않습니다.

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들어졌는지 확인합니다.

## 실행 방법

Windows PowerShell 기준입니다. 필요한 버전은 Node.js v22.23.3, Python 3.12.10입니다 (D-016).

### 처음 한 번

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
cd ..\frontend
npm install
```

### 매일 쓸 때 (D-013)

1. 화면 코드를 고친 뒤에만, `frontend` 폴더에서 화면을 빌드합니다.

   ```powershell
   npm run build
   ```

2. `backend` 폴더에서 서버를 켭니다. 이 창은 앱을 쓰는 동안 열어 둡니다.

   ```powershell
   .venv\Scripts\python -m uvicorn main:app --host 127.0.0.1 --port 8000
   ```

3. Chrome에서 `http://127.0.0.1:8000/`을 엽니다.
4. 끌 때는 서버 창에서 Ctrl+C를 누릅니다.

### 만드는 동안 (D-011, D-012)

1. `backend` 폴더에서 위 "매일 쓸 때" 2번과 같은 명령으로 서버를 켭니다.
2. 다른 창의 `frontend` 폴더에서 화면 개발 서버를 켭니다.

   ```powershell
   npm run dev
   ```

3. Chrome에서 `http://127.0.0.1:5173/`을 엽니다. 화면 코드를 고치면 바로 보입니다.

### 저장 파일

- 카드는 `backend/data/todo.db`에 저장됩니다. 서버를 처음 켤 때 저절로 생깁니다.
- 이 파일은 Git에 기록하지 않습니다. 지우면 카드가 모두 사라지고 되돌릴 수 없습니다.
