# 할 일 카드 웹앱

할 일을 카드로 만들고, 카드의 상태를 "할 일", "진행 중", "완료" 중 하나로 직접 바꾸는 웹앱입니다.

## 현재 상태

- 첫 버전을 완성했습니다 (2026-10-15). 요구사항과 설계 문서를 확정했고, 기능을 만들고 화면을 다듬었으며, 시험 시나리오 55개를 모두 통과했습니다. 작업별 기록은 PLAN.md에 있습니다.
- 두 번째 버전(회원가입·로그인, 여러 사람이 같은 네트워크에서 각자 계정으로 사용)을 만드는 중입니다 (2026-10-16). 회원가입·로그인 코드를 넣었고 (P-27), 첫 버전 카드는 모두 지웠습니다 (P-26, D-026). 남은 일은 두 계정 검수와 새 기준점입니다 (P-28). 작업은 PLAN.md P-24~P-28을 봅니다.
- 코드는 `frontend/`(화면: React, TypeScript, Vite)와 `backend/`(서버: FastAPI, 저장소: SQLite)에 있습니다. 카드 만들기, 상태 바꾸기, 고치기, 지우기가 됩니다. 칸에 방금 들어온 카드는 맨 아래에 놓이고, 화면 폭이 768px보다 좁으면 세 칸이 세로로 쌓이며, 저장·연결에 실패하면 화면 위쪽에 안내가 보입니다. 카드는 흰 바탕에 테두리가 있어 한 장씩 구분됩니다. 매일 쓸 때는 서버 하나만 켭니다 (D-013). 실행 방법은 아래 "실행 방법"을 봅니다.
- 이 폴더는 Git 저장소로 기록합니다 (D-005). 원격 저장소는 GitHub `pasta1513/todolist_vibe`(https://github.com/pasta1513/todolist_vibe)입니다 (D-022).
- 앱 안에는 AI 기능을 넣지 않습니다.

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들어졌는지 확인합니다.

## 실행 방법

Windows PowerShell 기준입니다. 필요한 버전은 Node.js v22.23.3, Python 3.12.10입니다 (D-016).

### 처음 한 번

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
cd ..\frontend
npm install
```

### 매일 쓸 때 (D-013)

1. 화면 코드를 고친 뒤에만, `frontend` 폴더에서 화면을 빌드합니다.

   ```powershell
   npm run build
   ```

2. 믿을 수 있는 네트워크(집·사무실 등)에 연결돼 있는지 확인합니다. 주고받는 내용이 암호화되지 않으므로, 카페 와이파이처럼 믿을 수 없는 네트워크에서는 서버를 켜지 않습니다 (D-024, ARCHITECTURE A-11).
3. `backend` 폴더에서 서버를 켭니다. 이 창은 앱을 쓰는 동안 열어 둡니다.

   ```powershell
   .venv\Scripts\python -m uvicorn main:app --host 0.0.0.0 --port 8000
   ```

4. 서버 컴퓨터에서는 Chrome이나 Edge로 `http://127.0.0.1:8000/`을 엽니다 (D-027).
5. 같은 네트워크의 다른 컴퓨터에서는 `http://<서버 컴퓨터 IP>:8000/`을 엽니다. 서버 컴퓨터의 IP는 PowerShell에서 `ipconfig`를 실행해 "IPv4 주소"를 봅니다. 열리지 않으면 서버 컴퓨터의 Windows 방화벽에서 8000번 포트를 허용해야 할 수 있습니다. 이 설정은 사람이 직접 합니다.
6. 끌 때는 서버 창에서 Ctrl+C를 누릅니다.

### 만드는 동안 (D-011, D-012)

1. `backend` 폴더에서 위 "매일 쓸 때" 3번과 같은 명령으로 서버를 켭니다.
2. 다른 창의 `frontend` 폴더에서 화면 개발 서버를 켭니다.

   ```powershell
   npm run dev
   ```

3. Chrome에서 `http://127.0.0.1:5173/`을 엽니다. 화면 코드를 고치면 바로 보입니다.

### 저장 파일

- 카드, 계정, 로그인 기록은 `backend/data/todo.db`에 저장됩니다. 서버를 처음 켤 때 저절로 생깁니다. 비밀번호는 원문이 아니라 바꾼 값으로 저장됩니다.
- 첫 버전에서 쓰던 모양의 저장 파일이면 서버가 켜지지 않고 안내만 보입니다. PLAN.md P-26대로 정리한 뒤 켭니다.
- 이 파일은 Git에 기록하지 않습니다. 지우면 카드가 모두 사라지고 되돌릴 수 없습니다.
