# 할 일 카드 웹앱

할 일을 카드로 만들고, 카드의 상태를 "할 일", "진행 중", "완료" 중 하나로 직접 바꾸는 웹앱입니다.

## 현재 상태

- 아직 만들기 전입니다. 코드는 없고 README.md, AGENTS.md, DECISIONS.md, PLAN.md, PRD.md만 있습니다.
- 이 폴더는 Git 저장소로 기록합니다 (D-005). 원격 저장소는 정하지 않았습니다.
- 앱 안에는 AI 기능을 넣지 않습니다.

## 프로젝트 문서

| 문서 | 내용 |
| --- | --- |
| README.md | 프로젝트 소개, 현재 상태, 시작·실행 방법 (지금 보고 있는 파일) |
| AGENTS.md | AI가 지켜야 할 작업 규칙 |
| DECISIONS.md | 사람이 확정한 결정 기록 |
| PLAN.md | 이번 목표, 작업 목록, 검증 결과, 남은 문제 |
| PRD.md | 첫 버전 요구사항: 넣을 기능, 기능 규칙, 넣지 않을 기능, 요구사항 후보와 검토 |

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들어졌는지 확인합니다.

## 실행 방법

아직 정하지 않았습니다. 앱을 만든 뒤 이곳에 적습니다.

## 확인과 기록

- 무언가를 만들거나 바꾸면 "현재 상태"를 그에 맞게 고칩니다.
- 새 문서를 만들면 "프로젝트 문서" 표에 추가합니다.
